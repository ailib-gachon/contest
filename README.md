# 가천대학교 생성형 AI 활용 사례 공모전 홈페이지

GitHub Pages에서 바로 게시할 수 있는 한국어 정적 홈페이지입니다. 별도 설치나 빌드 과정이 필요 없습니다. 기존 reference 및 시안 파일은 수정하지 않았습니다.

## 미리보기

`index.html`을 브라우저에서 열면 됩니다. 이메일 주소 복사는 브라우저 보안 설정에 따라 로컬 파일에서 제한될 수 있으며, GitHub Pages의 HTTPS 환경에서 지원됩니다.

## GitHub Pages 게시

1. GitHub에 홈페이지용 저장소를 만듭니다.
2. 이 폴더 **안의 내용**을 저장소 최상위에 올립니다. `index.html`, `styles.css`, `script.js`, `assets/` 및 `.nojekyll`을 포함합니다.
3. 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
4. Branch는 main, 폴더는 /(root)를 선택하고 저장합니다.
5. Pages 화면에 표시되는 주소로 접속합니다. 모든 자원은 상대 경로이므로 프로젝트 저장소 주소에서도 동작합니다.

현재 GitHub 인증 및 대상 저장소가 연결되어 있지 않아 공개 게시는 수행하지 않았습니다. GitHub Pages 설정 화면의 명칭은 변경될 수 있습니다.

## 확정 내용을 반영한 기준

- 대상 1팀 50만원, 우수상 3팀 각 30만원, 장려상 5팀 각 10만원: 총 9팀, 190만원. 상장 미지급.
- 가천대학교 직원 및 재학 중인 학부생·대학원생. 교원 제외. 개인 또는 1~4인 팀.
- 2026년 11월 2일~11월 23일 23:59 한국 시간 이메일 접수.
- 실제 수행한 사례만 허용. 팀당 1편, 중복 팀 참여 불가.
- 한국어 홈페이지. 별도 로그인·업로드·개인정보 저장 기능 없음.
- 제공받은 시행(안)을 기초로 작성. 시상 단위와 참가 자격은 사용자의 후속 확정 내용을 우선 반영.
- 메인 슬로건과 분야 소개 문장은 홈페이지용 편집 문구. '연구·학술' 표기는 기존 예시안 파일 분류에 맞춰 사용.

## 게시 전 남은 운영 확인

- 시행(안)의 일정·유의사항 등 최종 공고 내용 확인.
- 전체 ZIP 용량 및 대용량 파일 제출 경로 확정. 현재 담당자 문의로 안내.
- 사용자가 제공한 최종 참가신청서 및 분야별 예시안 PDF를 downloads/에 포함하고 다운로드 연결 완료.
- 만족도 조사 링크 준비.

## 다운로드 자료를 추가할 때

최종 공개용 파일을 `downloads/`에 저장합니다. 예: `application-form.pdf`, `case-examples.pdf`.
`index.html`의 해당 `.download-card`를 다음과 같은 링크로 교체합니다.

```html
<a class="download-card" href="./downloads/application-form.pdf" download>
  <span><strong>참가신청서</strong><small>PDF · 팀원 정보 및 동의서</small></span>
  <span>다운로드 ↓</span>
</a>
```

파일이 실제로 배포되었는지 확인하고 안내 문구에서 '준비 중'을 제거하세요. 설문은 제공받은 실제 설문 URL로 연결하세요.

## 파일 구성

- `index.html`: 참가 안내, 분야, 일정, 시상, 심사, 제출 방법, 자료 준비 상태, FAQ 및 유의사항
- `styles.css`: 화면 크기별 배치·인쇄·동작 줄이기 설정
- `script.js`: 모바일 메뉴, 한국 시간 기준 접수 상태, 이메일 복사
- `assets/`: 제공된 중앙도서관 및 학교 로고
- `downloads/`: 추후 공개용 자료 저장 위치

접수 상태는 방문자의 기기 시계를 기준으로 자동 변경됩니다. 메일 작성 버튼은 메일 앱만 열며 발송이나 파일 첨부를 자동으로 수행하지 않습니다.

일정 자동 표시: 한국 시간 기준 각 기간의 시작 자정에 진행 중, 마지막 날 다음 자정에 기간 종료로 전환합니다. 접수는 11월 2일 00:00~11월 23일 23:59까지입니다. 홍보와 접수는 겹치는 기간에 동시에 진행 중으로 표시됩니다. 결과 발표는 실제 게시 여부를 확인할 수 없으므로 발표 예정 / 발표 예정일 / 예정일 경과로 표시합니다. 방문 기기의 현재 시각으로 1초마다 갱신하고 탭 복귀 시에도 갱신합니다. 날짜 변경 시 index.html의 data-start/data-end 및 script.js의 접수 기간을 함께 수정합니다.
